## Upload the social preview

A separate 1280 × 640 PNG is provided with the project delivery. To set the actual GitHub repository preview:

1. Open the repository on GitHub.
2. Open **Settings → General**.
3. Find **Social preview** and choose **Edit**.
4. Upload the 1280 × 640 PNG and save.

The SVG artwork in this folder is the editable source; uploading it into the repository does not automatically configure GitHub's Social preview setting.

## Responsible discovery

Promote the project through real demonstrations, Odoo developer communities, issue discussions and useful technical articles. Use the project account transparently. Do not buy stars, use bots, impersonate users, or post repetitive unsolicited messages. Ask maintainers before presenting the tool as an official Odoo or OCA project.
